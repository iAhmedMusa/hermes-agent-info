Hermes Agent

A self-hosted personal automation assistant, operated by a single user.

Hermes Agent is a private, self-hosted assistant that I run on my own hardware for my own use. It helps me organise documents, track personal tasks and job applications, and automate routine work that would otherwise be done by hand.

This is a single-user personal project. It is not a commercial product, it is not offered as a service, and it has no users other than its owner.

What it does

  • Generates and organises personal documents such as CVs and application records.
  • Keeps a private tracking spreadsheet up to date.
  • Files finished documents into the owner's own storage.
  • Runs scheduled jobs that collect and summarise publicly available information.
  • Drafts emails for the owner to review, approve and send.

Why it uses Google APIs

The assistant connects to the owner's own Google account so it can work with files the owner already keeps there:

  • Gmail — to read and send mail on the owner's behalf, with the owner's explicit approval for each message sent.
  • Google Drive — to store and retrieve the owner's own documents.
  • Google Docs & Sheets — to read source documents and maintain a personal tracking spreadsheet.
  • Calendar & Contacts — to read scheduling and contact information for reminders.

Access is limited to the single Google account that authorises it. No other person's data is ever accessed.

How it runs

Hermes Agent runs on the owner's own machine. It is not hosted on a public server, has no public interface, and does not accept sign-ins from anyone else.
